📷 PUT YOUR PHOTOS IN THIS FOLDER.

1. Drop your image files right here (jpg / png / webp all work).
2. In src/content.js, write each file's exact name in a "file" field.

Example:
   You drop a photo named  beach.jpg  into this folder,
   then in content.js you write:   { file: "beach.jpg", caption: "our trip" }

The names in content.js already expect these files (rename yours to match,
or change the names in content.js — whichever is easier):
   hero.jpg
   us1.jpg  us2.jpg  us3.jpg  us4.jpg  us5.jpg  us6.jpg

Tip: portrait photos look best. Any photo you haven't added yet just shows
a little placeholder box, so nothing breaks while you're still collecting them.
